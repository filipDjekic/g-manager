# Istorijska dokumentacija

Arhiva čuva projektantski kontekst, stare zahteve, roadmap-e, stage izveštaje i prethodne rezultate. **Nije operativno uputstvo za trenutni release.** Neki dokumenti opisuju kasnije uklonjene ili nepostojeće funkcije; drugi najavljuju delove koji su u međuvremenu implementirani.

Aktuelni početak je [indeks dokumentacije](../README.md), a ograničenja su u [izveštaju pregleda](../MAINTENANCE_AUDIT.md).

| Direktorijum | Sačuvani materijal |
| --- | --- |
| `specifications/` | Root specifikacije i plan izrade; originalni project scope i zaseban stari backend scope |
| `roadmap/` | Master roadmap, dependency mapa, gap analiza i gaming/Client plan |
| `stages/` | Istorijski stage 18–27 izveštaji; njihove rezultate ovaj pregled nije ponavljao |
| `product-upgrade/` | Product/UX roadmap i stage 1–17 beleške |
| `ux/` | Raniji plan pojednostavljenja interfejsa |
| `ideas/` | Odložene ideje Documents/Workflow |
| `audits/` | System audit od 24. oktobra 2026. |

Identičan `gm/G-Manager-Plan-Izrade.md` spojen je sa [jedinom arhivskom kopijom plana](specifications/G-Manager-Plan-Izrade.md). Različiti scope dokumenti nisu izbrisani. Informacije iz starih Windows uputstava objedinjene su u [centralnom Client vodiču](../operations/WINDOWS_CLIENT.md).

JSON podaci u `docs/backend/measurements/` ostaju ranija merenja, ne aktuelni benchmark. Pri ponovnoj upotrebi proveriti commit, okruženje i metod merenja.
